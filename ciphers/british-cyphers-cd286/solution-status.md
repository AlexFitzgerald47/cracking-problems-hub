## Catalogue warning: CD 280 vs CD 286

Current Military Archives appendix labels the Tadhg Kennedy collection **C.D. 286**. A Kerry Library guide identifies the same Kennedy cipher collection as **C.D. 280**, including matching Group 2 item descriptions. Treat this as an archive-reference discrepancy until clarified. Any reproduction request should cite **Tadhg Kennedy + Group 2 + both CD 280 and CD 286** rather than trusting one number alone.
