# Public cipher and open-problem landscape

**Snapshot:** 2026-09-17. **Owner:** Hub orchestrator. **Purpose:** a watchlist of public projects, source collections and communities whose work could overlap with the Hub's ciphers, historical texts or research method. This is a discovery index, not a claim that every listed project is active, that its solve claims are validated, or that all public projects have been found.

The search included public GitHub repositories and project sites, historical-cryptography communities, and AI-assisted open-problem platforms. Entries link to the project's own repository or site. Generic AI-agent libraries, commercial cipher tools, cryptocurrency projects, one-off coursework and unsourced social posts are outside this list. A public project can appear after this snapshot; expand the index when one is found.

**Watch levels:** W = inspect weekly for overlapping solves and new target material; M = monthly for methods, datasets and projects; Q = quarterly or when a Hub target points there. Cadences are suggested checks during a future agent session. Nothing in this repository monitors these sources continuously.

## How to use and update this index

1. At the start of a cipher session, search this file for the target name, then check the relevant source itself. A project-level entry never establishes that a specific cipher remains unsolved.
2. During a weekly scan, inspect W entries for new case files, issue threads, papers, commits and revised solution statuses; visit M or Q entries at the suggested intervals or when a target overlaps. Record **date, exact changed URL, affected Hub target, and a short evidence note** in a new file under board/log/. The check cadence is a proposal, not an automated schedule.
3. For an overlapping claimed solve, preserve both versions of the work. Compare the primary source, transcription, key or proof, and date of public disclosure; route significant claims through the Hub's validator workflow. Credit independent work accurately.
4. For a useful external method, note its assumptions, license and a decisive control before adapting it. For a new target, follow the Hub's discovery brief and independently verify its open status.
5. Add newly found public hubs to a new dated board/log/ entry and propose an update to this index. The categories are for scanning effort, not rankings of research quality. Projects may change ownership, go quiet or disappear.
