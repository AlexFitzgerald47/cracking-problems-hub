## What changed

The owner asked for four things the board kept failing at without a human in the loop:
fair coverage across problems, promising work picked back up, no file forgotten, and
continuity inside a sector. The framework below is now the operating rule, written into
`_roles/README.md` (*The draw*), `_roles/BREAKER.md`, `_roles/ORCHESTRATOR.md`,
`_roles/FINDER.md`, `AGENT_INSTRUCTIONS.md`, `board/README.md` and the three routine prompts
(recorded in `board/SCHEDULE.md`).

1. **Streams.** A Ciphers, B Undeciphered texts, C Controversies, D Ireland. Each has a
   standing brief in `board/streams/`, owned by the orchestrator.
2. **Rotation.** Each Breaker firing takes the stream after the last Breaker session's
   (read from git history, so there is no shared state file to conflict over), and within
   it the unclaimed file with the highest coverage debt: days since a Breaker or Validator
   session × stage weight (held 2.0, in work 1.4, unworked 1.2, blocked 0.5). Blocked files
   never lead; panel-pending files are owed to Overwatch, not drawn.
3. **Pick-up.** A held claim idle for more than 14 days jumps to the front of its stream.
4. **No next move, no release.** A claim is released only with a concrete first item under
   `### Recommended next experiments` in `HANDOVER.md`.
5. **Discovery is live.** `discovered/` packs are drawn and claimable where they sit.

`npm run draw` prints the rotation, the pick and every stream's ranking. The site renders
the same computation (`scripts/derive.mjs`) and has a framework page.

## Why these particular rules

- **Coverage counts work, not edits.** Before this, "last touched" included orchestrator
  edits to `STATUS.md`, which made a file look worked on the day someone rewrote its row.
  The draw measures idle time from the last Breaker or Validator commit.
- **Rotation is stateless.** A rotation file would be exactly the shared, many-writer file
  `_roles/README.md` forbids.
- **The first draw was already informative.** On its first run it put VENONA BROWN/BRAUN
  under the pick-up rule (held, 20 days without a working session), sent stream B to four
  `discovered/` script packs that have never had a session, and listed Linear A and Byblos
  as panels owed to Overwatch since 09-17.
