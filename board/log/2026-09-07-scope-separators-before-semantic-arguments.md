# Scope separators before semantic arguments

**Source session:** `historical-texts/linear-a/`, 2026-09-07

A repeated failure mode in undeciphered administrative texts is to treat adjacent words as arguments of a relation before establishing which side of a divider/header they belong to.

Linear A HT117 made the cost visible. The surface sequence `MA-KA-RI-TE • KI-RO • U-MI-NA-SI •` tempts a binary reading such as `X KI-RO Y`. Wider contextual study instead supports `MA-KA-RI-TE • KI-RO •` as a higher-level heading, with following terms introducing sublists. The attempted debtor→creditor inference therefore arose from segmentation, not semantics.

The productive replacement was to classify KI-RO occurrences by **immediate separator/next-token type before interpreting them**. In the frozen clean sample:

- `KI-RO + numeral` predicts a scalar residual;
- `KI-RO •` predicts a forward-scoping residual/status block.

All 9 clean exact cases audited obey this split. The rule is now falsifiable on unseen records.

## Transferable practice

**Before assigning semantic arguments to an unknown marker, freeze its scope from punctuation, rulings, layout and next-token type.** Treat each possible scope direction as a separate construction. Only after scope classes are fixed should arithmetic, lexical parallels or role labels be used to interpret them.

This is stronger than the generic advice to respect physical segmentation: it specifically prevents a reproducible parser or attractive phrase-level reading from pointing at the wrong side of an operator.

When possible, record a construction grammar such as:

`MARKER + numeral -> scalar construction`

`MARKER + divider -> forward block`

and test it blind before translating either construction.
