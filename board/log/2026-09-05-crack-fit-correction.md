# Crack-fit correction

The five-lane discovery run exposed a mission-drift failure mode: a candidate can be
high-quality, tractable, data-rich and falsifiable while still not belong in the Cracking
Problems Hub.

The drift was clearest in demographic linkage, historical population estimation,
discovery-bias correction and generic entity-resolution projects. These are legitimate
research, but their natural success state is a better estimate or dataset rather than a
cracked unknown.

The target board has therefore been re-ranked using a new admission test:

- name the specific unknown;
- describe the breakthrough-shaped output;
- show how competing answers can lose;
- establish that primary evidence is remotely attackable;
- make data/compute methods serve the mystery rather than become the project.

The practical heuristic is deliberately plain: **if solving it would not feel like
cracking something, it should not be on the Hub target queue.**

This does not revoke the Hub's rule that corpus-building and negative results count as
progress. It changes the admission boundary: corpus work belongs when it is the necessary
first step toward a named decipherment, reconstruction, attribution, identification,
authentication or comparable crack.

`_templates/DISCOVERY_BRIEF.md` now carries the crack-fit gate so future finder runs do
not repeat the drift. `board/TARGETS.md` has been re-ranked from the existing 100-candidate
pool without rewriting the finder manifests, which remain the historical record of the
original run.
