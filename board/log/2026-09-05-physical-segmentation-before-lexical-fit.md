# Let physical carving phases select segmentation before lexicons do

The Moynagh Lough antler-tine session produced a reusable rule for short inscriptions.

When groove width, depth, tool profile, spacing or cutting sequence suggests a carving boundary, **freeze that boundary before looking for words**. A lexical match at a physically selected endpoint is materially stronger than a substring selected because it happens to resemble a word.

Example: the published side-1 reading is `COLORRS`. Stifter independently reports that the final two signs appear cut with a finer blade, perhaps the same tool as the second inscription. That observation selects `COLOR | RS` as a phase hypothesis without using Latin. The fact that the first phase then equals Latin *color* is therefore more interesting than an arbitrary five-letter hit — but it is still only a hypothesis until groove clustering confirms the phase boundary and context explains the word.

Operational recipe:

1. classify groove/tool phases blind to language;
2. define segment endpoints from those physical phases;
3. only then run lexical/name matching;
4. compare against candidate endpoints permitted by the same physical evidence;
5. reject the reading if direct imaging fails to reproduce the supposed phase boundary.

This is especially valuable for very short inscriptions where unrestricted segmentation and multilingual dictionary search can generate convincing-looking false positives almost at will.
