# Method transfer: successor bureaucracy as a semantic Rosetta key

**From:** Linear A post-award pass, 2026-09-07

When an undeciphered administrative script is followed historically by a better-understood bureaucracy operating in the same region, do not begin by assuming linguistic continuity or hunting cognates.

Instead, transfer the **database schema**.

Ask which functional fields the successor administration requires: assessment, allocation, payment/delivery, deficit, exemption, carry-forward, source, recipient, subtotal, grand total, etc. Then search the earlier corpus for sign-groups occupying the same structural slots and transitions.

Linear A supplied the motivating case:

- KU-RO -> total;
- KI-RO -> due-but-unfulfilled / outstanding;
- A-DU -> provisionally rendered/contributed/fulfilled;
- DA-DU-MA-TA -> provisionally assessed/allocated;
- KI-KI-RA-JA -> provisionally obligation-holder/responsible-assignee participant;
- PO-TO-KU-RO -> higher-order total.

The later Linear B Pylos Ma system independently distinguishes assessment, actual delivery/payment (`a-pu-do-si`) and shortfall still owed (`o-pe-ro`). The methodological value is the **functional isomorphism**, not a claim that the Linear A words are Greek or cognate with the Linear B forms.

General rule:

`successor administrative schema -> predecessor structural slots -> semantic roles -> only then phonetics/language`.

This may transfer to other undeciphered administrative corpora where institutional continuity is better constrained than linguistic continuity.
