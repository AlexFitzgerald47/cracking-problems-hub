# Short mixed-script inscriptions: geometry before lexicon

The Hunt Museum HCA 686 session produced a reusable method for very short inscriptions where script identity, orientation and linguisticity are all uncertain.

## 1. Separate four questions that are often collapsed

For each mark keep distinct:

1. **glyph geometry** — what strokes physically exist?
2. **script identity** — ogham, rune, Latin, technical mark, damage, etc.?
3. **phonetic/sign value** — if linguistic, what value?
4. **role** — phonetic sign, separator, direction mark, ornament, workshop mark, later addition?

A visually plausible letter does not automatically answer all four.

## 2. Branch the physical uncertainty before searching language

Write every serious orientation/value/direction branch to a machine-readable table. This exposes the real search budget. On HCA 686, a seemingly tiny five-mark object produced **64 unique phonetic branches** before any dictionary was opened.

This matters because a later lexical hit is one of 64 shots, not one pre-specified prediction.

## 3. Penalise rare analogues by attestation, not resemblance

A proposed HCA 686 `P` resembled a y-like `P` in Bern MS 207, but published scholarship reports that manuscript form as unattested elsewhere. A unique manuscript analogue should therefore carry a materially higher assumption cost than a common practical sign form.

General rule: **one exotic parallel does not equal a normal letter value**.

## 4. Use script register as evidence

Physical writing conventions can date/register an inscription before lexical fitting. HCA 686 has an artificial full stem-line; standard ogham references treat face/stem-line writing as later/scholastic rather than classical natural-edge ogham. That changes the prior over languages, formulae and likely users.

This generalises: baseline style, punctuation, ductus, carving surface and layout are evidence about *which corpus should even be searched*.

## 5. Compare object functions, not only sign shapes

The best HCA 686 comparison was not another mysterious five-sign sequence. Norse Greenland has inscribed soapstone casting moulds where legible texts give names/ownership. That does not solve Hunt, but it raises the prior for maker/owner/workshop marking on the same object class.

Search for **function parallels** as aggressively as exact glyph parallels.

## 6. Match the lexical search budget in the null

If there are 32 four-sign candidates and 32 five-sign candidates, apply all 64 shots to the null too.

A simple uniform illustration for a 20-symbol alphabet gives:

- ~19% chance of at least one exact hit against 1,000 entries per length;
- ~65% against 5,000 entries per length.

The exact percentages are model-dependent; the lesson is not. Tiny strings plus many branches make readable-looking matches cheap.

Therefore require a candidate to buy **independent constraints**: chronology, object function, script form, formula and physical orientation.

## 7. Historical morphology can kill perfect-looking matches

HCA 686 produced an attractive `ALUʀ` → Icelandic `alur` 'awl' idea. It failed because Old Norse is `alr`, while the epenthetic `u` belongs much later than the ordinary `ʀ` value window. A four-character visual match was defeated by historical phonology.

For any short lexical candidate, check the exact **historical stage and spelling**, not a modern descendant or dictionary headword.

## 8. Let lexical failure update the hypothesis class

If the physically favoured sequence repeatedly fails ordinary language/name corpora, do not endlessly mutate glyph values. Increase the posterior weight of:

- abbreviation;
- owner/maker initials;
- script practice/display;
- technical/terminal marks;
- non-lexical literate play;
- secondary additions.

This is especially important for portable objects.

## 9. Ask which physical observation collapses the branch tree

On HCA 686 the highest-value observation is not another word list. It is whether the fifth mark has the same tool profile/depth/patina as signs 1–4. If not, the five-sign premise disappears. Next are metric angle tests for signs 1 and 3 and incision sequencing at the stem-line.

General rule: after enumerating branches, rank **evidence by expected branch elimination**, not by ease of retrieval.

## Transferable workflow

`freeze grooves → enumerate branches → identify script/register → apply object priors → search corpora → matched null → historical-form check → rank hypotheses → specify branch-killing evidence`

This is the recommended default for future tiny, mixed-script or portable-inscription cracking targets.
