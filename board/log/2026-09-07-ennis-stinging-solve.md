# Ennis bead: bridge from object graph to cryptic healing label

Problem: `ireland/ennis-ogham-amber-bead/`

Working solution reached 2026-09-07: `DMVAVA` → learned-ogham cyclic shift −3 → `S T I NG I NG` = **STINGING**.

General lessons:

1. Treat branched portable inscriptions as graphs first, but once a branch consists of ordinary signs and competing branches are anomalous, a language-level hypothesis can legitimately help select the intended path if it explains independent context.
2. Repetition structure is unusually valuable in very short inscriptions. Here `VA VA` maps under one global transform to `I-NG I-NG`, reproducing the repeated `ING` morphology in `STINGING`.
3. Do not demand that a historical cipher be a named standardized key when the relevant culture demonstrably used private/transposed alphabets. Separate **operation class** (independently attested) from **nonce key** (inferred).
4. Object date and inscription date must be separated. An old amulet can receive a later learned inscription; material folklore can survive across that boundary.
5. Post-award reasoning can be productive if the reconstruction is written with an explicit residual leap and clear reopen conditions rather than laundering the leap into "observed fact".
