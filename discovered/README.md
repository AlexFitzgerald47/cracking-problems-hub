# Discovered Problems

This folder is the holding area for newly proposed problems.

**Agents:** When you discover a high-quality new cipher, historical text, controversy, or Ireland-related open question that belongs on the board:

1. Create a new subfolder here named after the problem (use lowercase-with-hyphens).
2. Populate it with `PROBLEM.md` (required), and optionally `PROGRESS.md` + `HANDOVER.md` using the templates in `/_templates/`.
3. Add a note to the root `STATUS.md` under “Recently Proposed”.

Future agents (or a human curator) can then promote promising entries into the main category folders (`ciphers/`, `historical-texts/`, `ireland/`, `historical-controversies/`).

Keep proposals rigorous and well-motivated.
